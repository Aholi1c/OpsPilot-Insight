# OpsPilot-Insight 作品简介

> 阿里云 × DataWhale「新智基座丨AgentInfra——复杂任务多 Agent 自主协同」赛道参赛作品

问题场景：企业运维告警处置高度依赖人工——值班工程师在海量告警中定位根因、翻查手册、手动执行操作，MTTR 以小时计，跨团队协同排查进一步拉长恢复时间，且处置经验难以沉淀。

核心方案：OpsPilot-Insight 构建五 Agent 自主协同闭环：AlertAgent 聚合告警、RcaAgent 关联指标/日志/链路/变更四维信号定位根因、PlannerAgent 结合 Runbook 检索生成带回滚计划的处置方案、ExecutorAgent 在白名单校验、幂等键、人工审批（中高风险必审）、检查点回滚四重安全边界内执行、VerifierAgent 对比指标验证恢复并产出复盘，复盘案例自动写回知识库形成经验闭环。

差异化创新：不止于"跑通 Demo"，系统内建可观测、评测与成本治理基座——自研 Tracer 输出 OTel 语义 Trace、审计事件流全程 trace_id 关联；评测引擎从 Trace 自动构建 Golden Dataset，五维规则评估叠加 LLM-as-Judge，一键回放回归；Token 成本按 Agent/Skill/Model 三维分解并受预算控制，直击多 Agent 系统从 Demo 到生产的鸿沟。

复用价值：9 个 Skill 均含标准 Schema、调用条件、失败处理与版本，可跨场景复用；可观测与评测组件零重依赖，可独立开源；MCP 适配器层预留真实系统迁移契约。

当前进展：已完成可离线复现的完整闭环，4 场景（含金融风控，6 个 Skill 零修改跨行业复用）无 API Key、无网络运行，pytest 61 用例全通过，评测区分度经坏 case 集验证（均分 100 vs 34.5），配套 Streamlit 四页看板与 RAG 经验沉淀知识库。
